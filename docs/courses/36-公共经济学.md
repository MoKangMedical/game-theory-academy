     3|> 每个人都想要好公路、好空气、好国防——但如果每个人都可以不付钱而享用，为什么还会有人付钱？

    12|## 核心概念
    13|
    14|### 公共品的双重特征
    15|
    16|公共品由两个关键属性定义：
    17|- **非竞争性（Non-rivalrous）**：一个人的消费不减少他人的消费（国防保护了A不能同时"消耗"掉B的保护）
    18|- **非排他性（Non-excludable）**：无法阻止不付钱者消费（无法阻止某人不享受清洁空气）
    19|
    20|这两个属性的结合创造了博弈困境：**个体理性导致集体非理性供给**。
    21|
    22|### 公共品供给博弈
    23|
    24|**离散版本**：
    25|n个人，公共品成本C，每人估值v_i。如果总估值≥C就应生产，但每个人有动机**低报**估值以减少自身分摊。
    26|
    27|**连续版本**：
    28|每个人选择贡献g_i，公共品总供给 G = Σg_i。个体i的效用：
    29|$$u_i = y_i - g_i + v_i(G)$$
    30|其中y_i是禀赋，g_i是贡献，v_i(G)是公共品带来的效用。
    31|
    32|纳什均衡（非合作）：
    33|$$v_i'(G^*) = 1 \quad \text{（公共品对i的边际效用=私人物品的边际效用=1）}$$
    34|
    35|社会最优（合作）：
    36|$$\sum_{j=1}^n v_j'(G^{opt}) = 1 \quad \text{（所有个体边际效用的总和=边际成本）}$$
    37|
    38|**关键比较**：
    39|$$G^* < G^{opt}$$
    40|
    41|非合作供给总是**低于**社会最优供给。差距随n增大而增大——人数越多，个体感觉自己的一分贡献"影响不了大局"，搭便车激励越强。
    42|
    43|### 搭便车问题的严重性：来自实验的证据
    44|
    45|实验室公共品博弈的十个常见发现：
    46|1. **一次博弈**：贡献率约40-60%的社会最优（比纯理性的0%高，但不达最优）
    47|2. **重复博弈**：贡献率随时间下降——最初合作，逐渐发现有人在搭便车→自己也减少贡献
    48|3. **允许惩罚**：引入"代价惩罚搭便车者"机制→贡献率大幅回升至接近最优
    49|4. **沟通**：允许参与者讨论（但不改变收益）→贡献率显著上升
    50|5. **群体规模**：规模越大，贡献率越低
    51|6. **MPCR**：边际人均回报越高（我的1分贡献给每个人带来的总收益越大），贡献越高
    52|7. **有条件合作者**：约50%的人是"条件合作者"——合作但前提是别人也在合作
    53|8. **搭便车核心**：约20-30%是稳定的搭便车者，几乎不贡献
    54|9. **排序效应**：按贡献倾向分组→合作者组成高贡献组，搭便车者组成低贡献组
    55|10. **启动效应**：初始几轮的行为强烈影响长期动态
    56|
    57|### 解决方案：税收作为强制合作
    58|
    59|**格罗夫斯-克拉克机制（Groves-Clarke mechanism）**：
    60|在理论上，可以设计一个激励相容的机制（每个人诚实报告估值是占优策略）：
    61|- 每人报告估值 \(\hat{v}_i\)
    62|- 如果 \(\sum \hat{v}_i \geq C\)，公共品被提供，否则不提供
    63|- 关键（pivotal）个体支付等于\(\max\{0, C - \sum_{j \neq i} \hat{v}_j\}\)
    64|
    65|**为什么现实中用税收而非GC机制？**
    66|GC机制的赤字问题——关键个体的支付总和<成本C→需要政府补贴。

   100|## 经典案例
   101|
   102|### 案例一：气候变化——史上最大的公共品博弈
   103|
   104|**结构**：
   105|- 公共品=稳定气候（非竞争、非排他）
   106|- 参与者=195个国家
   107|- 行动=减少碳排放（成本由国家承担，收益由全球共享）
   108|- 搭便车激励=极大（n=195，每个国家的"关键性"几乎为零）
   109|
   110|**博弈逻辑**：
   111|每个国家的理性计算：如果我减排，我的成本完全自己承担，但减排收益（避免气候变化）的99.5%流向其他国家→我的投资回报率极低→理性的策略=不减排，等别人减。
   112|
   113|这就是为什么《巴黎协定》选择了"自愿承诺NDC"(国家自主贡献)而非强制目标——在如此多参与者的公共品博弈中，强制执行近乎不可能。全球正在见证人类历史上规模最大的"囚徒困境"在上演。
   114|
   115|### 案例二：开源软件——为何没有价格却有产出？
   116|
   117|**悖论**：开源软件是纯公共品（非竞争、非排他），为何它的供给远高于搭便车理论的预测？
   118|
   119|**博弈论解释**：
   120|- 信号激励：高能力程序员通过开源贡献向雇主发送"我是牛人"的信号（与第16课信号博弈的联系）
   121|- 声誉经济：GitHub星星、contributor排名→将公共品"私有化"为个人声誉
   122|- 互惠规范：大公司（Google、Meta）使用开源→回头贡献开源→长期的互惠期待
   123|- 互补品：开源软件本身免费，但围绕它的收费服务（咨询、培训、SaaS托管）是盈利的
   124|
   125|## 核心洞见
   126|
   127|> **公共品困境是人类合作规模的根本限制**：从原始部落到全球气候治理，公共品博弈决定了人类合作的上限。每一个"我们需要合作"的呼吁，都在与一个强健的纳什均衡——"别人做，我搭车"——作斗争。成功的社会制度，本质上是找到了把这一均衡从"零供给"拉到"高供给"的机制。
   128|
   129|## 练习
   130|
   131|**练习1（计算）**：离散公共品。n=3，C=60。真实估值v1=25, v2=25, v3=20。总估值=70>C→该建。若按估值比例分摊，每人支付 vi×(C/Σv_i)，各人的净效用是多少？谁有动机说谎？
   132|
   133|<details><summary>查看答案</summary>
   134|总70>60→建！分摊：p1=25×(60/70)=21.4，p2=21.4，p3=17.1。
   135|净收益：u1=25-21.4=3.6，u2=3.6，u3=20-17.1=2.9。三人都正→都应同意。
   136|但如果一人决定吹小牛（v1报告10）：新总55<60→不建→v1损失25的真实值但只省了约21的分摊→净损失。吹牛的动机取决于v_i对总和的"关键性"。
   137|</details>
   138|
   139|**练习2（分析）**：为什么疫苗接种可以建模为公共品博弈？"群体免疫"和搭便车有什么关系？
   140|
   141|<details><summary>查看答案</summary>
   142|疫苗的外溢效应：接种者不仅保护了自己，还降低了病毒的传播概率→保护了未接种者。
   143|公共品博弈结构：n个个体，接种者承担成本+c，创造公共品（减少疾病传播）。
   144|个体理性：我不接种（成本0）——如果别人都接种了，群体免疫保护了我（搭便车成功）。
   145|集体理性：所有人接种→病毒消灭→最优结果。
   146|现实：总有人搭便车→接种率不足→群体免疫阈值达不到→疾病持续传播。
   147|这就是为什么许多国家强制儿童疫苗：将公共品从中"自愿提供"转为"强制提供"。
   148|</details>
   149|
   150|**练习3（案例）**：维基百科是一个"奇迹"——数十万人免费贡献内容。从公共品博弈+信号博弈角度解释它的成功。
   151|
   152|<details><summary>查看答案</summary>
   153|(1)低贡献成本：编辑一个条目比写一篇论文容易得多——降低了贡献门槛。
   154|(2)高参与可见度：贡献者的名字在条目历史中可见→声誉信号。
   155|(3)规范与内在动机：贡献者内化了"知识应免费共享"的文化规范。
   156|(4)渐进参与：先是小修改→逐渐成为专家→阶梯式投入→沉没成本锁定。
   157|(5)精英管理：活跃编辑形成社区→更强的"公众感"→从全局公共品变为"俱乐部品"。
   158|(6)与气候谈判的关键差异：贡献成本极低+立即可见的满足感+强声誉回馈。
   159|</details>
   160|
   161|**练习4（计算）**：连续公共品。两人，u_i=y_i-g_i+ln(G)，G=g1+g2。求纳什均衡供给G*和社会最优供给G**并比较。
   162|
   163|<details><summary>查看答案</summary>
   164|i的边际效用：∂u_i/∂g_i = -1 + 1/G = 0 → G=1（对两个玩家都如此）。
   165|纳什：G*=1（每人贡献0.5或任何一个组合达G=1）。
   166|社会最优：max Σu_i = (y1+y2-G) + 2lnG → -1 + 2/G = 0 → G** = 2。
   167|G* = 1 < G** = 2！非合作供给恰好是社会最优的一半。
   168|结论：搭便车导致公共品供给不足，不足程度与n成正比。
   169|</details>
   170|
   171|**练习5（思考）**：如果全球实施"全球碳税"（所有国家统一碳价格），从博弈论角度分析它的可行性障碍和克服方案。
   172|
   173|<details><summary>查看答案</summary>
   174|障碍（一）：主权问题——国际社会缺乏强制执行机制→搭便车和退出激励极大。
   175|障碍（二）：分配不公——发展中国家"历史排放少"但承担碳税成本高→公平性争议。
   176|障碍（三）：承诺问题——没有任何国家能做出不可撤销的"长期碳税"承诺→先动者可能被利用。
   177|克服方案：用博弈中常用的"条件承诺"结构——
   178|(a)碳关税(Border Carbon Adjustment)：对来自无碳税国家的进口征收碳税→消除非参与者的竞争优势。
   179|(b)俱乐部方案：形成高减排俱乐部→俱乐部内自由贸易→将搭便车者排除在贸易利益之外→激励参与。
   180|(c)匹配承诺：每个国家承诺"每1美元其他国家征的碳税，我加倍匹配"→正反馈激励机制。
   181|</details>

### 🔍 延伸思考与练习

> 博弈论最终是一门"如何思考"的学科——观察世界的新角度。当你学会从博弈视角看问题，你会发现：几乎所有人类互动都有其"均衡"和"偏离均衡"的解释。

---

#### 快速检验
**Q**: 想象你是"机制设计者"——你可以重新设计一个规则来解决你生活中的某个问题。你会怎样改变规则来引导所有人走向更好的均衡？
<details><summary>查看答案</summary>
机制设计的核心洞察：与其在博弈中挣扎，不如改变博弈本身。比如：把"谁洗碗"的囚徒困境改为"轮流洗碗"的协调博弈；把"加班竞赛"改为"看产出不看出勤"的委托代理优化。改变规则比在规则里挣扎更有效。
</details>

**Q**: 在这门课中学到的最反直觉的一个结论是什么？
<details><summary>查看答案</summary>
许多博弈论结论是反直觉的：比如在囚徒困境中，理性且自利的个体得到的是最坏的结果；在零和博弈中，混合策略（随机化）比"找出最优纯策略"更强。博弈论告诉我们：直觉在多人互动中常常出错——需要系统分析。
</details>
