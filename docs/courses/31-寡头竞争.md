# 第31课：寡头竞争

> 当市场只有两三个玩家时，他们不是在竞争——他们在下一盘棋，每一步都在揣测对方的下一步

## 学习目标
- 掌握三种寡头竞争模型：古诺(产量竞争)、伯川德(价格竞争)、斯塔克伯格(序贯竞争)
- 理解"竞争越激烈，价格越接近边际成本"的连续谱
- 分析合谋（卡特尔）的稳定性条件和背叛激励
- 比较不同竞争模式下的市场结果：价格、产量、利润与社会福利
- 运用寡头博弈分析真实市场：航空、电信、电商平台和半导体产业

## 核心概念

### 古诺竞争（Cournot, 1838）

**设定**：两个企业（双寡头）生产同质产品，同时选择产量 q₁, q₂。市场价格为逆需求函数 P(Q) = a - bQ，其中 Q = q₁ + q₂。边际成本为常数 c（假设对称）。

**策略分析**：
企业1的最优反应函数（Best Response Function）：
$$BR_1(q_2) = \arg\max_{q_1} q_1(a - b(q_1 + q_2) - c)$$

一阶条件：\(a - 2bq_1 - bq_2 - c = 0\)
$$q_1^* = \frac{a-c}{2b} - \frac{q_2}{2}$$

**纳什均衡**：两条反应曲线的交点
$$q_1^* = q_2^* = \frac{a-c}{3b}, \quad Q^* = \frac{2(a-c)}{3b}, \quad P^* = \frac{a+2c}{3}, \quad \pi_i^* = \frac{(a-c)^2}{9b}$$

**关键性质**：
- 价格高于边际成本（P* > c）→存在超额利润（古诺租金）
- 产量低于完全竞争水平（Q_竞争 = (a-c)/b > Q*_古诺）
- 价格低于垄断水平（P_垄断 = (a+c)/2 > P*_古诺）
- 企业数 n → ∞ 时，古诺均衡趋近完全竞争

**勒纳指数**（Lerner Index，衡量市场势力）：
$$L = \frac{P - MC}{P} = \frac{a-c}{a+2c}$$

在古诺双寡头中，L 反映了市场势力的大小。n→∞时 L→0（完全竞争），n=1时 L=(a-c)/(a+c)（垄断最大值）。

### 伯川德竞争（Bertrand, 1883）

**设定**：两个企业生产同质产品，同时选择价格 p₁, p₂。消费者全部从低价企业购买。

**伯川德悖论**：
如果 p₁ < p₂：企业1获得全部市场需求 D(p₁)
如果 p₁ = p₂：市场平分
如果 p₁ > p₂：企业1需求为零

在纯策略中：
- 任何 p_i > c 都不是均衡（对手稍降价即可获取全部市场）
- p₁ = p₂ = c 是唯一纯策略纳什均衡
- 均衡利润：π₁ = π₂ = 0！

**伯川德悖论的含义**：仅需两家企业，同质产品的价格竞争就能产生完全竞争的结果——利润归零。这与直觉（"寡头应该能赚超额利润"）严重矛盾。

**伯川德悖论的解决方案**：
1. **产品差异化**：产品不完全替代→即使p₁>p₂，部分消费者仍购买产品1
2. **产能约束**（Edgeworth解法）：企业受产能限制，无法服务整个市场→高价有利可图
3. **重复博弈**：长期关系中，企业通过触发策略维持高价→默契合谋
4. **信息不完美**：消费者不知道所有价格（搜索成本）→单企业有一定定价权
5. **转换成本**：已有客户粘性→即使对手价格更低

**伯川德-纳什均衡中的混合策略**：
当纯策略均衡存在问题时（如产能约束），企业可能采用混合策略——以一定概率分布随机定价。这比纯策略的零利润更接近现实。

### 斯塔克伯格竞争（Stackelberg, 1934）

**设定**：企业1（领导者）先选择产量 q₁，企业2（追随者）观察到 q₁ 后选择产量 q₂。

**博弈树**：
1. 企业1选择 q₁
2. 企业2观察到 q₁，选择 q₂
3. 价格由 P = a - b(q₁+q₂) 决定

**子博弈精炼均衡**：
用逆向归纳求解第二阶段：追随者的最优反应为
$$q_2 = BR_2(q_1) = \frac{a-c}{2b} - \frac{q_1}{2}$$

第一阶段：领导者预期到追随者的反应，最大化
$$\pi_1 = q_1(a - b(q_1 + BR_2(q_1)) - c) = q_1\left(\frac{a-c}{2} - \frac{bq_1}{2}\right)$$

一阶条件：
$$q_1^* = \frac{a-c}{2b}, \quad q_2^* = \frac{a-c}{4b}$$

$$P^* = \frac{a+3c}{4}, \quad \pi_1^* = \frac{(a-c)^2}{8b}, \quad \pi_2^* = \frac{(a-c)^2}{16b}$$

**先动优势（First-Mover Advantage）**：
- 领导者产量是古诺均衡的3/2倍
- 追随者产量只有古诺均衡的3/4倍
- 领导者利润是追随者的两倍（古诺时利润相等）
- 但总产量大于古诺→价格更低→消费者受益

**先动优势的来源**：领导者通过"承诺"大规模产出，构成可置信威胁，迫使追随者削减产量。这在古诺的同时博弈中是不可能的——因为没有承诺机制。

**承诺的价值**：
先动优势提示了博弈论中一个更深刻的原理——在某些博弈中，限制自己的选项（如"承诺高产量"）反而能获得更好的结果。这不是"越多选择越好"——有时战略性地放弃灵活性才是最优策略。

### 合谋与卡特尔稳定性

合谋问题本质是囚徒困境在寡头竞争中的体现：

| | 合作(限制产量) | 背叛(扩张产量) |
|---|-------------|-------------|
| 合作 | 各得垄断利润/2 | 背叛者得大部分利润 |
| 背叛 | 受害者亏 | 各得古诺利润 |

**合谋稳定性条件**（触发策略，Trigger Strategy）：
企业采用"冷酷触发策略"：只要对方一直合作，我就合作；对方背叛一次，我从此永远回到古诺竞争。

合作条件：
$$\frac{\pi^{\text{合谋}}}{1-\delta} > \pi^{\text{背叛}} + \frac{\delta \pi^{\text{古诺}}}{1-\delta}$$

其中 δ 是折现因子（反映未来重要性）。解出：
$$\delta > \frac{\pi^{\text{背叛}} - \pi^{\text{合谋}}}{\pi^{\text{背叛}} - \pi^{\text{古诺}}}$$

**关键影响因素**：
- 企业数 n 越多→合作越难（单个企业的背叛收益更大，惩罚更难）
- 市场透明度高→背叛行为更快被发现→合谋更易维持
- 需求波动大→背叛动机增强（"趁高需求捞一笔"）
- 进入壁垒高→新进入者不会破坏合谋
- 折现率高（企业短视）→合谋破裂

### 寡头竞争的政策含义

**市场集中度与福利**：
- 赫芬达尔-赫希曼指数（HHI）= Σ(市场份额)²
- HHI < 1500：非集中市场（反垄断审查宽松）
- 1500 ≤ HHI ≤ 2500：中等集中（审慎审查）
- HHI > 2500：高度集中（严格审查）

**合并模拟（Merger Simulation）**：
反垄断机构使用寡头模型模拟合并后的价格效应——对每种假设的竞争模式（古诺、伯川德、拍卖等）计算合并前后的均衡价格差。

## 经典案例

### 案例一：OPEC——最著名的卡特尔及其反复崩溃

**背景**：石油输出国组织（OPEC）自1960年以来试图通过协调成员国产量来控制全球油价。成员国包括沙特阿拉伯、伊朗、伊拉克、委内瑞拉等13国。

**古诺vs合谋分析**：
- 合谋最优策略：各成员国大幅减产，使总供给接近垄断产量→获取垄断利润
- 但每个成员国的古诺最优反应：在其他国家减产时自己偷偷增产（背叛激励）
- 博弈结构：总利润 = 公共品（高油价对所有成员有利，但易搭便车）

**历史动态（五个阶段）**：
1. **1973-1980：强合谋期**。石油禁运+需求刚性→油价从$3/桶飙升至$35。各成员享受高油价收益。
2. **1980-1986：合谋弱化期**。高油价吸引非OPEC增产（北海、阿拉斯加），OPEC市场份额下降。沙特承担大部分减产负担，其他成员偷偷增产。
3. **1986：价格战**。沙特宣布不再保护"免费搭车者"，放弃减产→油价暴跌至$10。
4. **1999-2014：有限的重新协调**。亚洲需求增长→OPEC重新获得部分定价权。但成员国之间存在持续的"囚徒困境"张力。
5. **2014-2016：再次破裂**。美国页岩油革命→OPEC面临新的竞争者。沙特再次发起价格战→油价从$100+跌至$30。

**博弈论教训**：
- OPEC的困境是经典的古诺冲突——每个成员国的"背叛"符合个体理性但伤害集体利益
- 沙特作为"大玩家"具有不对称的角色——它必须做出不对称的牺牲来维持合谋，但也因此获得不对称的议程设置权
- 当外部进入者（页岩油）改变了市场结构，原有的合谋均衡从根本上一去不复返——这是结构决定行为的经典验证

### 案例二：中国外卖市场的双寡头博弈

**背景**：美团外卖vs饿了么——中国本地生活服务市场中持续时间最长的双寡头竞争。截至2023年，美团占~65-70%，饿了么占~30-35%。

**分阶段博弈分析**：

**阶段1：伯川德价格战（2015-2018）**
两家以巨额补贴抢夺用户和骑手：
- 对用户：$1吃外卖、免费配送
- 对骑手：高单价+高补贴
- 博弈逻辑：这是"烧钱抢市场"的伯川德式竞争——市场份额的当前价值远超短期亏损
- 均衡接近：P ≈ 补贴后价格 << MC（谁撑不住谁先退出/被收购）

**阶段2：差异化（2018-2020）**
缓解伯川德悖论的手段：
- 美团：外卖+到店+酒店+出行（构建生态飞轮）
- 饿了么：阿里生态协同（淘宝/支付宝流量入口、饿了么+盒马+高德）
- 差异化维度：供给（独家餐厅）、技术（算法效率）、生态互补
- 博弈效果：差异化削弱了伯川德的极端竞争——即使价格略高也不会立即失去所有用户

**阶段3：默契稳定（2020至今）**
- 补贴退坡→两家默契地减少直接价格战
- 竞争转向：运力效率、服务品质、生态深度
- 博弈解释：这类似于触发策略均衡——双方都知道无休止的价格战会两败俱伤，而默契的"价格稳定"对双方都有利

**网络效应带来的特殊性**：
- 外卖平台是典型的双边市场——更多的用户吸引更多餐厅，更多餐厅吸引更多用户
- 赢家通吃倾向：美团的市场份额领先产生了自我强化的飞轮
- 但多归属（multi-homing）缓解了绝对垄断——许多骑手和用户同时使用两个平台
- 这使均衡偏离了伯川德（价格>边际成本存在超额利润），但也不是纯粹的垄断

### 案例三：Intel vs AMD——半导体双寡头的古诺博弈

**背景**：全球x86 CPU市场几乎完全由Intel和AMD两家企业占据，形成了长达数十年的双寡头竞争格局。

**古诺博弈特征**：
1. **产能是核心策略变量**：芯片制造需要巨额前期投资（晶圆厂建设成本$100-200亿），产能规划的提前期长（2-3年）→接近古诺的"产量选择"
2. **产品存在差异但不完全替代**：Intel性能略优但更贵，AMD性价比更高
3. **创新周期作为动态博弈**：每一代新芯片都是一个新的"回合"，两家在性能、功耗和定价上博弈

**关键博弈事件**：
- **2006-2016**：Intel的"Core架构"领先→AMD被迫在价格段竞争（接近追随者角色）
- **2017-2022**：AMD的Ryzen/Zen架构突破→性能反超，市场份额从~10%上升至~40%（博弈格局逆转）
- **产能竞逐**：两家都在先进制程（Intel的18A, AMD依赖台积电的3nm/2nm）上进行巨额投资

**斯塔克伯格维度**：
由于Intel拥有自有晶圆厂而AMD依赖代工，Intel在产能扩张上具有一定程度的"先动者"优势。但台积电的先进制程赋予了AMD"时间套利"——在特定时期反超。这是全球供应链对寡头博弈的深刻影响：博弈不再只取决于企业自身，还取决于它们的供应链伙伴。

## 核心洞见

> **伯川德悖论揭示了"竞争是魔鬼"**：仅需两家企业，同质产品的价格竞争就能将利润归零——这一数学事实说明，为什么现实中的企业不惜一切代价追求差异化。不是因为差异化让产品"更好"——而是因为差异化是逃避伯川德零利润地狱的唯一出路。企业品牌的本质，不是获得"溢价"，而是逃避"归零"。

> **先动优势的本质是承诺权力**：斯塔克伯格模型的深层启示是——在策略博弈中，能够做出"不可撤销承诺"的一方可以重塑博弈格局。领导者的先动不是简单的"抢先"，而是通过改变博弈路径，迫使追随者在"领导者的阴影下"最优化。先动优势的大小取决于该承诺的可置信程度。

> **合谋的悖论：越想要越得不到**：卡特尔的内在矛盾在于——维持合谋需要每个成员牺牲短期利益来维持长期高价，但恰恰是长期高价带来的高利润，增加了每个成员背叛的诱惑。一个成功的卡特尔必须同时解决"外部进入"（新竞争者的威胁）和"内部背叛"（成员的囚徒困境）两个问题——而这两者往往是冲突的。

(b) P*=120-60=60。
(c) π₁=π₂=30×(60-30)=900。
(d) L=(P-MC)/P=(60-30)/60=0.5。

**练习2（分析）**：古诺模型中，如果企业1的成本从c₁=30降至c₁=10，而企业2成本保持c₂=30，新均衡下两家企业的产量和利润如何变化？这种"成本非对称"对竞争格局有什么影响？

<details>
<summary>查看答案</summary>
企业1反应函数：q₁=(110-q₂)/2。企业2反应函数：q₂=(90-q₁)/2。
联立：q₁=130/3≈43.3, q₂=70/3≈23.3。Q≈66.7, P≈53.3。
π₁=43.3×(53.3-10)=1878, π₂=23.3×(53.3-30)=543。
成本优势效应：企业1的产量增加了44%（从30到43.3），利润翻倍以上。企业2的产量下降了22%，利润下降40%。成本优势在古诺竞争中的杠杆效应是非线性的。
更一般的：Δq₁*=(c₂-c₁)/3b, Δq₂*=-(c₂-c₁)/3b。成本每拉开1单位，产量差距拉开2/3b单位。
</details>

**练习3（计算）**：斯塔克伯格竞争。P=200-Q, c₁=c₂=20。求领导者、追随者的产量和利润。

<details>
<summary>查看答案</summary>
追随者反应：q₂=(180-q₁)/2。
领导者：max q₁[q₁+ (180-q₁)/2 - 20? No... max q₁(200-q₁-q₂(q₁)-20)] = max q₁(180-q₁-(180-q₁)/2) = max q₁(90-q₁/2)。
一阶：∂/∂q₁=90-q₁=0, q₁=90。q₂=45。Q=135, P=65。
π₁=90×45=4050, π₂=45×45=2025。
对比：古诺均衡：q₁=q₂=180/3=60, P=200-120=80, π=60×60=3600。领导者从3600→4050(+12.5%)，追随者从3600→2025(-43.8%)。
</details>

**练习4（计算）**：合谋稳定性。双寡头市场中，合谋利润=5000，背叛单期利润=7000，古诺竞争利润=3000。折现因子δ=0.6。合谋是否稳定？

<details>
<summary>查看答案</summary>
合谋稳定条件：5000/(1-δ) ≥ 7000 + δ×3000/(1-δ)。
5000/0.4 ≥ 7000 + 0.6×3000/0.4。
12500 ≥ 7000 + 4500 = 11500。
12500 ≥ 11500 → 成立！合谋在δ=0.6下是稳定的。
临界δ：5000/(1-δ) = 7000 + 3000δ/(1-δ) → 5000 = 7000(1-δ) + 3000δ → 5000 = 7000 - 7000δ + 3000δ → 5000 = 7000 - 4000δ → δ=0.5。
δ≥0.5时合谋稳定。
</details>

**练习5（思考）**：数字经济中，算法定价（Algorithmic Pricing）如何改变寡头博弈的动态？提出两种可能的政策应对方案。

<details>
<summary>查看答案</summary>
**改变机制**：
(1) 速度革命——算法可以在毫秒内调整价格而非人类需要数周→"博弈频率"爆炸式增长
(2) 信息对称化——算法可以爬取和推断对手的成本和策略→不完全信息假设弱化
(3) 合谋无交流——多个独立AI可能通过强化学习自发收敛到超竞争价格，无需任何"协议"或交流
(4) 个性化价格——算法使完美价格歧视成为可能→伯川德逻辑逆转（每个消费者面对不同价格）

**政策方案**：
方案A：算法审计——要求企业提交定价算法的逻辑说明，由监管部门定期审查是否存在"算法合谋"的迹象
方案B：定价延迟规则——人为引入价格更新延迟（如"价格变动最小间隔24小时"）以降低博弈频率和算法协同的空间
方案C：开放算法竞争——强制公开核心定价参数，让消费者和小竞争者"看穿"定价逻辑→增加市场透明度
方案D：算法共谋标准——修改竞争法，将"算法间无人类指令的默契协调"也纳入合谋违法的范围

**深层悖论**：如果AI定价效率极高且降低消费者价格，这似乎是好事。但当AI"学会合谋"而提价时，这是谁的错？没有电话、没有邮件、没有人说"我们提价吧"——只有两个神经网络通过市场数据不约而同地发现了超竞争均衡。法律语言中的"协议"或"协同行为"是否能涵盖这种情况？
</details>

## 趣味元素

**博弈论笑话**：
> 两个古诺寡头走进一家酒吧。第一个说："我要一杯啤酒。"第二个说："考虑到他的最优反应，我也要半杯啤酒。"
> 酒保问："你们是经济学家吗？"
> "不，"他们说，"我们是均衡解。"

**历史冷知识**：
安东尼·奥古斯丁·古诺（Antoine Augustin Cournot，1801-1877）在1838年发表他的寡头理论时，几乎没有引起任何关注。他的著作被尘封了整整半个世纪，直到1890年代马歇尔重新发现他。而古诺本人不仅是经济学家，还是数学家和哲学家。今天博弈论最基本的"纳什均衡"概念——在古诺的双寡头分析中已经有清晰的雏形，比纳什早了110多年。
