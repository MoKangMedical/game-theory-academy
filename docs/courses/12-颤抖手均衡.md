# 第12课：颤抖手均衡

> 即使是"颤抖的手"，也要在均衡中站稳——泽尔腾对理性边界的最后一道防线

## 学习目标

- 理解颤抖手均衡的概念、数学定义与精炼逻辑
- 掌握泽尔腾（Reinhard Selten）对纳什均衡的进一步精炼思路

- 理解颤抖手均衡与序贯均衡、适当均衡之间的逻辑关系

## 核心概念

### 什么是颤抖手均衡

1975年，泽尔腾发表论文《A Reexamination of the Perfectness Concept for Equilibrium Points in Extensive Games》，正式提出"颤抖手均衡"（Trembling Hand Perfect Equilibrium）。这个名称本身就蕴含着深刻的直觉：在一场博弈中，即使每个玩家都是理性的，他们的"手"仍然可能以极小的概率发生"颤抖"——即因为注意力分散、信息传输误差、执行失误等原因，错误地选择了非最优策略。

一个真正稳健的均衡，必须在考虑到这种"颤抖"扰动的可能性之后依然成立。换句话说：如果某个均衡依赖于"对手绝不会犯某个错误"的假设，那么这个均衡在颤抖手的检验下就不合格——因为现实中，人的手确实可能"颤抖"。

颤抖手均衡由此成为博弈论精炼体系中承上启下的关键概念：它比纳什均衡更强（排除了更多"不合理"的均衡），但又不像某些更强的精炼概念那样过于苛刻。

### 形式化定义

设有一个有限 n 人标准式博弈 G，每个玩家 i 有纯策略集合 S_i，混合策略集合 Σ_i。

**定义（ε-扰动博弈）**：对任意 ε > 0，构造一个扰动博弈 G(ε)，其中每个玩家 i 的每个纯策略 s_i ∈ S_i 必须以至少 ε/|S_i| 的概率被选择。换言之，玩家的混合策略必须属于：

$$\Sigma_i^\varepsilon = \{\sigma_i \in \Sigma_i : \sigma_i(s_i) \geq \varepsilon/|S_i| \text{ 对所有 } s_i \in S_i\}$$

这里，每个纯策略被分配了一个最低概率下限——策略不能"完全消失"。

**定义（颤抖手均衡）**：策略组合 σ* = (σ*_1, ..., σ*_n) 是 G 的颤抖手均衡，当且仅当存在一列 ε^k → 0+ 和一列对应的完全混合策略组合 σ^{ε^k}，使得：

1. 对每个 k，σ^{ε^k} 是扰动博弈 G(ε^k) 的纳什均衡
2. 当 k → ∞ 时，σ^{ε^k} → σ*

通俗地讲：颤抖手均衡是"一系列越来越小的扰动博弈的纳什均衡的极限点"。随着颤抖概率 ε 趋近于零，扰动均衡收敛到的那个策略组合，就是颤抖手均衡。

### 为什么需要"完全混合策略"？

这里的"完全混合策略"（completely mixed strategy）意味着每个纯策略都以严格正的概率被选择——哪怕概率极小。这与"颤抖"的直觉一致：玩家无法完全避免选择某个策略，即使该策略是"错误"的。

如果一个纳什均衡中，某个玩家以零概率选择某个策略（即：该策略被"确定地排除"），那么这个均衡就需要接受颤抖手的检验：如果对手以微小概率意外地选择了那个被排除的策略，你的最优反应是否依然是当前策略？

### 标准式与扩展式的区别

泽尔腾在提出颤抖手均衡时，区分了两种情形：

**标准式颤抖手均衡（Strategic-Form Trembling Hand Perfect）**：
- 在博弈的标准式（矩阵）表示中定义
- 所有纯策略（包括不同信息集上）共享同一个 ε 参数
- 检验方式：所有策略的概率下限同时趋近于零

**扩展式颤抖手均衡（Extensive-Form Trembling Hand Perfect）**：
- 在博弈树结构中定义
- 每个信息集上的行动有独立的扰动概率
- 考虑了博弈的阶段性和信息结构的层级性
- 等价于"序贯均衡"（Kreps & Wilson, 1982）在"完全混合策略"条件下的特例

两者并不等价。存在这样的博弈：某个策略组合在标准式下是颤抖手均衡，但在扩展式下不是。这是因为扩展式的扰动更加"局部化"——不同信息集上的颤抖可以被独立处理。

### 颤抖手均衡 vs 子博弈精炼均衡

子博弈精炼均衡排除了"不可信威胁"，但它的排除力量有限——它只能排除那些在"非均衡路径"上的不可信行为。颤抖手均衡走得更远：

| 对比维度 | 子博弈精炼均衡 | 颤抖手均衡 |
|---------|---------------|-----------|
| 排除范围 | 仅排除子博弈上的非均衡行为 | 排除任何依赖于"零概率事件"的均衡 |
| 扰动模型 | 无扰动（完全理性） | 微小概率的随机失误 |
| 精炼强度 | 较弱 | 较强 |
| 适用性 | 仅适用于有proper子博弈的扩展式博弈 | 适用于任意有限博弈 |

颤抖手均衡可以排除那些即使不涉及完整子博弈，但仍然"不合理"的均衡。例如，依赖于"对手绝不会选择某个被占优策略"的均衡，在颤抖手检验下就会崩溃。

### 存在性定理

一个重要且令人安心的结果是：

**定理**：每个有限博弈至少存在一个颤抖手均衡。

这意味着颤抖手均衡并非"过于严格以致于不存在"的概念——它既有精炼力，又有存在性保证。这比起某些更强的精炼概念（如"适当均衡"）更具实用价值。

## 经典案例

### 案例1：进入阻挠博弈——不可信威胁的崩溃

**背景**：这是产业组织理论中最经典的博弈之一。一家在位垄断企业面对潜在进入者。在位企业可以在进入发生前"威胁"：如果新企业进入市场，我们将发动毁灭性的价格战。

**博弈结构**（扩展式）：
- 第一阶段：进入者选择"进入"或"不进入"
- 第二阶段（如果进入发生）：在位者选择"降价"或"不降价"
- 收益：
  - (不进入, —)：进入者得0，在位者得垄断利润 5
  - (进入, 不降价)：进入者得2，在位者得2（双寡头分享市场）
  - (进入, 降价)：进入者得-1，在位者得-1（价格战双输）

**纳什均衡分析**：这个博弈有两个纳什均衡：
- (不进入, 降价威胁)：进入者选择不进入，在位者的策略是"如果你进入我就降价"。这是个纳什均衡，因为在位者的威胁（如果在均衡路径上从未被触发）不会改变收益。
- (进入, 不降价)：这是唯一的子博弈精炼均衡，因为在位者的降价威胁在子博弈中不是最优反应——价格战对在位者自己也是亏损的。

**颤抖手检验**：
现在引入颤抖手逻辑。假设在位者有一个微小的概率 ε > 0 会"颤抖"——即在第二阶段意外地选择不降价（而非坚持降价威胁）。

进入者的期望收益计算：
- 如果选择"进入"：以概率 (1-ε) 在位者降价（得 -1），以概率 ε 在位者不降价（得 +2），期望收益 = (1-ε)×(-1) + ε×2 = -1 + ε + 2ε = -1 + 3ε
- 如果选择"不进入"：确定得 0

当 ε → 0 时，进入者的期望收益 → -1 < 0。等等，这似乎意味着进入者不该进入？

关键在于ε的定义方向。在颤抖手均衡的构造中，我们考虑在位者的"均衡策略"是降价，但允许他以概率ε意外选择不降价。如果"降价"是均衡策略，则"不降价"是颤抖方向。进入者预期在位者大概率降价（得-1），所以不该进入——这与子博弈精炼的结论矛盾？

实际上，这里需要更细致的分析。真正的颤抖手检验是这样的：我们考虑扰动博弈序列 G(ε) → G。在位者的完全混合策略中，降价概率为 1-ε₁，不降价概率为 ε₁（其中ε₁ ≥ 某个下限）。当在位者的均衡策略实际上是不降价（即(进入,不降价)均衡）时，降价才是颤抖方向。进入者预期在位者以 (1-ε₁) 概率不降价（得 +2），以 ε₁ 概率降价（得 -1），期望收益 = (1-ε₁)×2 + ε₁×(-1) = 2 - 3ε₁。

当 ε₁ → 0 时，期望收益 → 2 > 0。因此进入者选择进入是最优的。

那 (不进入, 降价) 这个纳什均衡呢？在位者的均衡策略是降价。如果进入者意外进入（以概率ε₂），在位者坚持降价（均衡策略），进入者得-1。进入者期望收益 = -1 < 0，所以不进入确实是最优反应？但是！

问题出在：要让在位者的"降价威胁"在扰动博弈中构成均衡策略，在位者必须在每个纯策略上至少分配概率下限。在位者既有"降价"也有"不降价"两个纯策略——他不能完全排除"不降价"。一旦在位者以概率下限选择了"不降价"，进入者就有正概率获得 +2 的收益。这使得(不进入, 降价威胁)不再是扰动博弈的纳什均衡——因为进入者可以通过以正概率选择进入来获得更高的期望收益。

**最终结论**：只有 (进入, 不降价) 是颤抖手均衡。颤抖手均衡排除了那个依赖于不可信威胁的纳什均衡。

**启示**：颤抖手均衡的精炼逻辑不只是理论洁癖——它有实际的行为含义。如果市场参与者认识到"犯错是人类天性"，那么基于"威胁者绝不会心软"的均衡就无法维持。这解释了为什么在现实中，寡头垄断市场中的进入威胁通常需要可置信的承诺机制（如沉没成本、产能投资、声誉建设）来支撑。

### 案例2：蜈蚣博弈中的逆向归纳与颤抖手

**背景**：蜈蚣博弈（Centipede Game）是一个经典的扩展式博弈，它挑战了逆向归纳法与人类实际行为之间的张力。Rosenthal（1981）提出后，成为行为博弈论的重要实验范式。

**博弈结构**（以4阶段为例）：
- 两个玩家轮流选择"继续"或"停止"
- 每次"继续"会增加总奖池，但选择权交给对方
- 收益结构：越晚停止，总收益越大；但如果你选择"继续"而对方在下一轮"停止"，你得到较少

具体收益（以经典的"递增奖池"版本为例）：
- 第1轮：玩家1选择——停止 (1,0)，继续→
- 第2轮：玩家2选择——停止 (0,2)，继续→
- 第3轮：玩家1选择——停止 (3,1)，继续→
- 第4轮：玩家2选择——停止 (2,5)，继续→ (4,4)

**逆向归纳分析**：
- 最后一轮（第4轮）：玩家2选停止得5 > 继续得4，所以选停止
- 倒数第二轮（第3轮）：玩家1知道玩家2会在第4轮停止，自己继续得2 < 停止得3，所以选停止
- 以此类推……第1轮玩家1就应该停止
- 逆向归纳均衡：(第1轮停止, 每轮都停止)

**颤抖手检验**：
在颤抖手均衡框架下，每个玩家在每一轮都以至少 ε 的概率"颤抖"选择"继续"（即使理性策略是"停止"）。

考虑玩家1在第1轮的决策。如果玩家1继续：
- 玩家2可能以 ε 概率颤抖选择继续 → 玩家1获得更高收益的机会
- 这个微小的"希望"改变了第1轮的计算

在扰动博弈 G(ε) 中，由于每一轮都有正概率"继续"，玩家1在第1轮选择"继续"的期望收益不再是确定性的逆向归纳结果。当 ε 足够大时，"继续"甚至可以是严格更优的。

然而，随着 ε → 0，扰动博弈的均衡确实收敛到逆向归纳均衡：第1轮停止。蜈蚣博弈的唯一颤抖手均衡仍然是逆向归纳解。

**实验与理论的分歧**：
- 实验室中，玩家很少在第1轮就停止——大多数对局会进行到第3轮或更远
- 但与颤抖手理论预测一致的是：随着玩家经验和博弈轮数的增加，行为确实向逆向归纳方向收敛
- 这暗示颤抖手逻辑本质上是一种"极限理性"概念——它描述的是"如果玩家足够有经验且错误概率足够小"时的行为

**启示**：颤抖手均衡作为"极限理性"基准，帮助我们区分"短期行为偏差"与"系统性非理性"。即使在存在颤抖的环境中，随着学习过程，行为最终会趋向颤抖手均衡。

## 核心洞见框

> **核心洞见1**：颤抖手均衡的核心不是"人会犯错"，而是"人不能保证绝对不犯错"。正是这个微小的"不能保证"，使得那些依赖于"对方绝对不会做某件事"的均衡崩溃。

> **核心洞见2**：颤抖手均衡是"极限理性"概念的数学表达——它描述的不是真实人类的行为（人类当然会犯错），而是"如果错误概率无限趋近于零，理性行为会收敛到哪里"。这使得它成为精炼概念的理想基准。

> **核心洞见3**：在应用层面，颤抖手均衡的精炼力告诉我们：要设计一个稳健的机制或合同，不能假设参与者"永远不会犯错"或"永远不会偏离"。好的机制应该在面对微小扰动时依然能引导参与者走向理想的均衡。

> **核心洞见4**：颤抖手均衡的存在性定理（每个有限博弈至少有一个）确保了精炼概念不会"过度精炼"——它消除了不合理的均衡，但不会消除所有均衡。

- 策略A对A：(5, 5)
- 策略A对B：(0, 0)
- 策略B对A：(0, 0)
- 策略B对B：(3, 3)

请验证：两个纯策略纳什均衡 (A, A) 和 (B, B) 是否都是颤抖手均衡？混合策略纳什均衡 (3/8概率选A, 3/8概率选A) 是否也是？

<details>
<summary>查看答案</summary>
(A, A) 是颤抖手均衡：当对手以 1-ε 概率选A、ε概率选B时，A的期望收益 = (1-ε)×5 + ε×0 = 5(1-ε)，B的期望收益 = (1-ε)×0 + ε×3 = 3ε。当 ε 足够小时，5(1-ε) > 3ε，A仍然是最优反应。同样，(B, B) 也是颤抖手均衡。

混合策略均衡也是颤抖手均衡。在混合均衡中，每个策略都以正概率被选择（本身就是"完全混合"的），对任何微小扰动都能保持最优反应条件。事实上，所有"正规"的混合策略纳什均衡都是颤抖手均衡。
</details>

**练习3（案例应用）** 在囚徒困境中，唯一的纳什均衡（背叛, 背叛）是颤抖手均衡吗？请给出严格的论证。

<details>
<summary>查看答案</summary>
是的，(背叛, 背叛)是颤抖手均衡。论证如下：

囚徒困境收益矩阵（T > R > P > S）：
- 设对手以概率 1-ε 选背叛、ε 选合作
- 自己选背叛的期望收益 = (1-ε)×P + ε×T = P + ε(T-P)
- 自己选合作的期望收益 = (1-ε)×S + ε×R = S + ε(R-S)

背叛 - 合作的收益差 = (P-S) + ε[(T-P) - (R-S)]

由于 P > S（背叛对合作时背叛方得更多），且当 ε → 0 时，收益差 → P-S > 0，所以背叛始终是最优反应。

更简单的论证：背叛是严格占优策略——无论对手以何种混合策略（包括任何完全混合策略），背叛的期望收益都严格大于合作。因此，背叛是对任何扰动的最优反应，(背叛, 背叛)必然是颤抖手均衡。
</details>

**练习4（判断正误）** "每个子博弈精炼均衡都是颤抖手均衡。"请判断这个说法的真伪，并说明理由。

<details>
<summary>查看答案</summary>
这个说法在**扩展式博弈**中不一定成立。反例：存在某些博弈，其中某个策略组合是子博弈精炼均衡但不是扩展式颤抖手均衡。原因在于：子博弈精炼均衡只排除了子博弈上的非均衡行为，但可能依赖于博弈树中非子博弈节点的"零概率信念"；而扩展式颤抖手均衡要求每个信息集上的行为都对局部扰动稳健。

但在**标准式**中，每个颤抖手均衡是子博弈精炼均衡的一个子集——即标准式颤抖手均衡 ⇒ 子博弈精炼均衡（在扩展式博弈转化后），但反之不必然。

简单记忆：对于一般的有限扩展式博弈——
颤抖手均衡（扩展式）⊆ 序贯均衡 ⊆ 子博弈精炼均衡 ⊆ 纳什均衡
</details>

**练习5（思考题）** 在实际的经济制度设计中，颤抖手均衡的概念有什么启示？请结合"金融监管"或"合同设计"的实例加以说明。

<details>
<summary>查看答案</summary>
在金融监管中：如果监管规则依赖于"银行绝不会冒险做某类投资"的假设，那么这个规则框架是脆弱的——因为银行可能因各种原因"颤抖"（风控失误、代理人问题、系统漏洞）而从事高风险行为。一个稳健的监管框架应该考虑到这种"颤抖"的可能性，设置足够的资本缓冲和风险隔离机制，使得即使在"银行可能犯错"的前提下，系统性风险仍然可控。

在合同设计中：如果合同条款假定"供应商绝对不会延期交付"，那么这个合同在现实中很脆弱。更好的做法是明确约定延期的后果（违约金、应急方案），使得即使在"颤抖"（延期）发生时，合作仍然可以维持。这正是"不完全合同理论"（Hart & Moore）的核心精神——合同不可能预见所有偶然事件，但好的合同框架应该在各种可能的"偏离"下仍然给出合理的激励。

核心启示：颤抖手均衡的方法论告诉我们，稳健的制度设计不应该依赖于"参与者完美执行"的假设，而是应该构建对"可能的错误"具有弹性的规则体系。
</details>
