     1|# 第2课：纳什均衡——博弈的静止点
     2|
     3|> 如果每个玩家都在做"给定别人正在做的事，我能做的最好的事"，那么没人有理由改变——这就是纳什均衡。它是博弈论中最重要的单一概念。
     4|
     5|## 学习目标
     6|- 精确定义纳什均衡——纯策略和混合策略版本
     7|- 掌握"最佳反应函数"方法——纳什均衡在哪里交叉
     8|- 学会用消去法、划线法和最佳反应法求解纳什均衡
     9|- 理解纳什均衡的多重性与"精炼"的必要性
    10|- 将纳什均衡映射到商业策略、价格战、政治竞选和人际决策
    11|
    12|## 核心概念
    13|
    14|### 纳什均衡的形式定义
    15|
    16|给定一个有n个玩家的博弈，每个玩家i有策略空间S_i和收益函数u_i。一个**纳什均衡**是一个策略剖面 s* = (s*_1, s*_2, ..., s*_n)，使得对于每个玩家i：
    17|
    18|> u_i(s*_i, s*_{-i}) ≥ u_i(s_i, s*_{-i})    ∀ s_i ∈ S_i
    19|
    20|即：没有任何玩家可以通过单方面偏离来获得更高收益。
    21|
    22|### 混合策略纳什均衡
    23|
    24|当纯策略纳什均衡不存在时（如硬币匹配博弈），我们需要**混合策略**——每个玩家以概率分布随机化自己的行动：
    25|
    26|> σ_i 是S_i上的概率分布。 u_i(σ_i, σ_{-i}) = Σ_s (Π_j σ_j(s_j)) · u_i(s)
    27|
    28|**纳什定理(1950)**：任何具有有限玩家和有限策略的博弈都存在至少一个混合策略纳什均衡。
    29|
    30|这就是纳什获得诺贝尔奖的工作——证明"均衡总是存在的"（尽管不一定是纯策略）。
    31|
    32|### 最佳反应函数
    33|
    34|**定义**：对于玩家i，最佳反应函数BR_i(σ_{-i}) = {σ_i : u_i(σ_i, σ_{-i}) ≥ u_i(σ'_i, σ_{-i}) ∀ σ'_i}
    35|
    36|纳什均衡 = 所有最佳反应函数的交点：
    37|> σ*_i ∈ BR_i(σ*_{-i})   ∀ i
    38|
    39|**几何直觉**：想象两个玩家的BR曲线。它们的交叉点就是纳什均衡。如果有多个交点→有多重均衡。

    54|### 纳什均衡求解方法速查
    55|
    56|| 方法 | 适用场景 | 步骤 |
    57||------|---------|------|
    58|| 划线法 | 2×2纯策略博弈 | 对每列，标出玩家1最佳反应；对每行，标出玩家2最佳反应→双划线格子=NE |
    59|| 连续消去严格劣策略 | 策略多且有劣策略的博弈 | 反复删除"无论如何都更差"的策略 |
    60|| 最佳反应函数 | 连续策略博弈（如古诺） | 求BR_i(s_{-i})→解联立方程 |
    61|| 等值期望法 | 混合策略 | 设对手混合使你的策略等收益→解概率 |
    62|| 不动点迭代 | 大规模博弈 | 数值求解r = BR(r) |

    64|## 经典案例
    65|
    66|### 案例一：古诺双头垄断
    67|
    68|**设定**：两家公司选产量q₁, q₂。价格P = a - (q₁+q₂)。边际成本c。利润πᵢ = (P - c)qᵢ。
    69|
    70|**求解**：公司1的问题：max_q₁ π₁ = (a - q₁ - q₂ - c)·q₁
    71|→ 一阶条件：a - 2q₁ - q₂ - c = 0
    72|→ BR₁(q₂) = (a - c - q₂)/2
    73|→ 对称→ q*₁ = q*₂ = (a - c)/3
    74|→ 总产量Q = 2(a - c)/3，价格P = (a + 2c)/3
    75|
    76|**对比垄断和完全竞争**：
    77|- 垄断产量：Q_mon = (a - c)/2，价格(a+c)/2
    78|- 古诺产量：Q_cour = 2(a - c)/3（高于垄断）
    79|- 竞争产量：Q_perf = (a - c)（最高）
    80|
    81|结论：双头古诺博弈的均衡生产量在垄断和完全竞争之间——两家公司相互竞争提高了产量、压低了价格，使消费者受益。
    82|
    83|### 案例二：公路博弈（Route Choice）
    84|
    85|**设定**：100辆车从A到B。两条路：路1时间=50分钟固定；路2时间=0.5×n分钟（n为选路2的车数）。每个人独立选路→总时间最短。
    86|
    87|**均衡**：设x人选路2。路2时间=0.5x，路1时间=50。均衡要求无车想换路→0.5x = 50 → x = 100。但100>100？不行。
    88|精确：x人路2→时间0.5x。100-x人路1→50。换路无益→0.5x = 50 → x=100→全部100人选路2。但路2=50=路1。可以。均衡：所有100人选路2，时间50分钟。
    89|总出行时间=50×100=5000分钟。
    90|
    91|**社会最优**：min T = (100-x)·50 + x·0.5x = 5000 - 50x + 0.5x² → dT/dx = -50 + x = 0 → x* = 50。最优：50人路2，50人路1。总时间=50×25 + 50×50 = 3750分钟。
    92|
    93|**博弈论洞见**：均衡（全是路2）总5000分钟 > 最优3750分钟——这就是"交通拥堵的外部性"：每个人用路2的行为增加了其他人的通行时间，但个人不考虑这一外部性。纳什均衡≠社会最优。
    94|
    95|## 核心洞见
    96|
    97|> **均衡不代表"好"，只代表"稳"**：纳什均衡告诉你"给定别人在做什么，你没有理由改变"。它不说这是好的——囚徒困境的均衡是最糟糕的结果。认清这个区别是博弈论启蒙的第一步。
    98|
    99|> **看不见的手的失效**：亚当·斯密说自利→社会最优。纳什均衡证明这句话不总是成立。在存在外部性的博弈中，每个人做对个体最好的事，整体结果可能糟透了。

   117|纯策略NE：(上,左)和(下,中)。
   118|</details>
   119|
   120|**练习2**：混合策略均衡。硬币匹配博弈：两玩家选H或T。都相同→玩家1赢(+1对-1)；不同→玩家2赢(-1对+1)。求纳什均衡。
   121|
   122|<details><summary>查看答案</summary>
   123|无纯策略NE。设玩家1以p选H，玩家2以q选H。
   124|玩家1收益：对方H→己H:+1,己T:-1。期望E1 = p[q·1+(1-q)·(-1)] + (1-p)[q·(-1)+(1-q)·1] = p(2q-1)+(1-p)(1-2q)=2p(2q-1)+1-2q。
   125|要使无偏离，对p的导数=0→2(2q-1)=0→q*=1/2。
   126|对称→p*=1/2。
   127|唯一NE：双方以1/2随机选H/T。期望收益均为0。
   128|</details>
   129|
   130|**练习3**：古诺博弈n个公司。a=120, c=20, n家公司。求纳什均衡产量和价格，分析n→∞时趋近完全竞争。
   131|
   132|<details><summary>查看答案</summary>
   133|公司i：max πᵢ = (120 - Q - 20)qᵢ, Q = Σqⱼ
   134|FOC: 120 - 2qᵢ - Σ_{j≠i}qⱼ - 20 = 0 → 2qᵢ = 100 - Σ_{j≠i}qⱼ
   135|对称→qᵢ = q ∀i → 2q = 100 - (n-1)q → (n+1)q = 100 → q* = 100/(n+1)
   136|Q* = n·q* = 100n/(n+1)
   137|P* = 120 - 100n/(n+1) = (20n+120)/(n+1)
   138|n=1: q=50, P=70（垄断）
   139|n=2: q=33.3, P=53.3（双头）
   140|n=5: q=16.7, P=36.7
   141|n→∞: q→0, P→20=c（完全竞争）
   142|</details>
   143|
   144|**练习4**：为什么纳什均衡在"一次性博弈"中预测力最强？在重复博弈中呢？
   145|
   146|<details><summary>查看答案</summary>
   147|一次性博弈中，均衡是最强大的预测工具——因为"没有明天"意味着声誉、报复、合作承诺全部失效。只有纳什均衡是自执行(self-enforcing)的结果。
   148|在重复博弈中，纳什均衡仍然成立，但"多了一个维度"：今天的选择影响未来的互动。这允许比一次性博弈更多的均衡——"民间定理"说几乎任何结果都可以是某种重复博弈的纳什均衡。
   149|所以纳什均衡在重复博弈中依然必要——但不够"锋利"了，因为均衡太多。
   150|</details>
   151|
   152|**练习5（开放）**：找出现实生活中的一个"非纳什均衡"局面——大家都想做某事的当前状态不是均衡。解释每个人会怎么偏离以及新的均衡方向。
   153|
   154|<details><summary>查看答案</summary>
   155|例1：拥挤的免费公路。车都在公路上→但每个人的"最佳反应"是继续留在公路(因为离开无法改善自己的通行时间)→是均衡吗？若一条路极堵，另一条空→堵的车单方面去空地更快→非均衡。要所有路时间相等才是均衡。
   156|例2：教室安静。第一人说话→没人制止→更多人说话→最终都说话(均衡迁移)。
   157|例3：社交媒体。朋友都在A平台→你也去A(NE)。如果新来者选B更舒适→可能迁移→A不再是均衡。
   158|</details></details>

### 🎯 深度学习：打通理论与直觉

> 学博弈论不是为了记住一百个定义——是为了形成**博弈直觉**。当你看到一个多人竞争的场景，自动识别出博弈类型、均衡候选和偏离激励——你就真正消化了这门学问。

---

#### 进阶练习
**练习A — 案例迁移**：选择一个你生活中的真实场景（朋友聚会费、项目分工、价格谈判），用本课的博弈论框架重新分析。写下：
1. 玩家及各自的策略空间
2. 回报函数（你的假设）
3. 预测的纳什均衡
4. 实际发生的结果
5. 若两者不同，为什么？

<details><summary>参考框架</summary>
- 第一步：画博弈表格或树，明确所有可行的选择组合。
- 第二步：标出每个结果的回报值——即便只是推断。
- 第三步：逐格检查——有没有人有动机单方面换策略？没有的那格就是纳什均衡。
- 第四步：对比现实——若现实与均衡不同，可能是信息不对称、非理性行为、或你定义的回报函数有误。
</details>

**练习B — 反事实分析**：假定博弈的一个关键条件改变了（例如：从一次性博弈变成了重复博弈，或信息从不对称变为完全对称），均衡会如何变化？这对现实决策有什么启示？

<details><summary>提示</summary>
- 重复博弈→引入声誉和惩罚→合作均衡可能出现（TFT生效）。
- 信息从不完全变完全→信号不再需要→均衡可能更简单也更残酷（买家知道你的成本底线）。
- 这种"如果…就…"的思维练习，正是博弈论的实战价值所在。
</details>

**练习C — 机制设计挑战**：如果你可以在这个博弈中引入一条新规则（如：信息披露要求、顺序改变、惩罚机制），你会设计什么样的规则来改善结果？这条规则需要满足什么条件才能自执行？

<details><summary>思路参考</summary>
一个"好"的机制要满足：(a) 激励相容——人们自愿遵守；(b) 个体理性——参与比不参与好；(c) 预算平衡（若是经济机制）——不需要外部资源补贴。例如：从"谁洗碗"改成"轮流洗碗+不洗的一方负责明天做饭"——既激励相容，又不需要外部裁判。
</details>
