# 第15课：鹰鸽博弈

> 为什么自然界中的争斗总是有限的？——因为彻底的对抗意味着彻底的毁灭

## 学习目标

- 掌握鹰鸽博弈的收益结构和混合策略纳什均衡
- 理解"资源价值V"与"战斗成本C"如何决定演化结果
- 运用复制动态分析鹰鸽种群中策略频率的演化
- 理解鹰鸽博弈在生物行为、经济竞争和人类冲突中的广泛应用
- 将鹰鸽博弈与囚徒困境、协调博弈进行比较分析

## 核心概念

### 鹰鸽博弈的起源

鹰鸽博弈（Hawk-Dove Game）由梅纳德·史密斯和普莱斯（Maynard Smith & Price, 1973）在开创演化博弈论的经典论文中提出，原始名称是"鹰鸽博弈"（Hawk-Dove），旨在解释一个看似矛盾的自然现象：为什么动物之间的争斗通常遵循某种"仪式化"规则，而不是真正拼死一搏？

假设两个动物争夺一个价值V的资源（如领地、食物或配偶），每个个体有两种策略可选：
- **鹰（Hawk）**：战斗到底，直到获胜或重伤
- **鸽（Dove）**：展示威胁，但如果对方真的进攻就退缩

如果鹰遇到鸽：鹰获得资源（+V），鸽安全撤退（0）。
如果鸽遇到鸽：双方平分资源各得V/2。
如果鹰遇到鹰：双方激战，获胜者得V，但双方都付出代价。假设胜负概率相等，期望收益 = V/2 - C/2 = (V-C)/2。

### 收益矩阵

标准化处理（令V为资源价值，C为战斗成本）：

| | 鹰(H) | 鸽(D) |
|---|-------|-------|
| 鹰(H) | (V-C)/2, (V-C)/2 | V, 0 |
| 鸽(D) | 0, V | V/2, V/2 |

### 关键参数：V/C 比值

鹰鸽博弈的全部行为由**资源价值与战斗成本的比值 V/C** 决定。这个比值的变化会导致完全不同的演化结果。

**情况一：V > C（值得拼命）**
资源价值超过战斗成本。此时(V-C)/2 > 0，鹰对鸽的优势(V>0)大于鹰对鹰的劣势。鹰严格占优于鸽——博弈退化为类似囚徒困境的结构，唯一纳什均衡是双方都选鹰。

**情况二：V < C（不划算拼命）**
这是鹰鸽博弈最经典的也是最有趣的情况。此时(V-C)/2 < 0——鹰对鹰是双输（负期望收益）。没有纯策略纳什均衡，存在唯一的混合策略均衡。

### 混合策略纳什均衡

当V < C时，设p为选择鹰策略的概率。混合策略均衡要求：

$$u(H, p) = u(D, p)$$

$$p \cdot \frac{V-C}{2} + (1-p) \cdot V = p \cdot 0 + (1-p) \cdot \frac{V}{2}$$

解出均衡鹰比例：
$$p^* = \frac{V}{C}$$

这意味着：在混合策略均衡中，选择鹰的比例等于资源价值与战斗成本的比值。

**直觉解释**：
- 如果资源价值 V 相对战斗成本 C 越大，鹰的比例越高（越值得冒险）
- 如果战斗成本 C 越高（如争端可能导致严重伤害），鹰的比例越低
- 在极限 V/C → 1 时，p* → 1（几乎全是鹰）
- 在极限 V/C → 0 时，p* → 0（几乎全是鸽）

### 复制动态分析

考虑一个无限大的混合种群，鹰的比例为p。期望收益：

$$u(H) = p \cdot \frac{V-C}{2} + (1-p) \cdot V = V - p\frac{V+C}{2}$$
$$u(D) = p \cdot 0 + (1-p) \cdot \frac{V}{2} = \frac{V}{2}(1-p)$$

复制动态方程：
$$\frac{dp}{dt} = p(1-p)\left[V - p\frac{V+C}{2} - \frac{V}{2}(1-p)\right] = p(1-p)\left[\frac{V}{2} - p\frac{C}{2}\right]$$

整理得：
$$\frac{dp}{dt} = \frac{1}{2}p(1-p)(V - pC)$$

不动点：p*=0, p*=V/C, p*=1。

稳定性分析（V < C）：
- p*=0：dp/dt ≈ (1/2)p·V > 0 → **不稳定**（少数鹰可以侵入全鸽种群）
- p*=V/C：dp/dt在p<V/C时为正，p>V/C时为负 → **渐近稳定**（混合均衡是演化稳定状态）
- p*=1：dp/dt ≈ -(1/2)(1-p)(C-V) < 0 → **不稳定**（少数鸽可以侵入全鹰种群）

**关键生物学启示**：无论初始种群是全鸽还是全鹰，演化力都会把种群推向混合均衡p*=V/C。这就是为什么自然界中的战斗通常维持在一定限度——过度好斗（鹰）和过度和平（鸽）都不是演化稳定的。

## 数据表格

### 鹰鸽博弈的参数空间

| V/C 比值 | 博弈类型 | 均衡结构 | 演化结果 | 现实映射 |
|----------|---------|---------|---------|---------|
| V/C → 0 | 几乎无价值 | p*→0，近乎全鸽 | 仪式化展示 | 无毒蛇的威慑姿态 |
| V/C = 0.3 | 温和竞争 | p*=30%鹰 | 多数鸽少数鹰 | 灵长类群体冲突 |
| V/C = 0.5 | 中等竞争 | p*=50%鹰 | 鹰鸽各半 | 商业谈判中的强硬/妥协 |
| V/C = 0.7 | 激烈竞争 | p*=70%鹰 | 多数鹰少数鸽 | 创业公司市场竞争 |
| V/C > 1 | 生死之战 | 唯⼀均衡：全鹰 | 鹰占优→类似囚徒困境 | 灭国级别战争 |

### 鹰鸽博弈与其他经典博弈的比较

| 特征 | 囚徒困境 | 鹰鸽博弈 | 协调博弈 |
|------|---------|---------|---------|
| 纯策略纳什均衡数 | 1 (背叛,背叛) | 0 (V<C时) | 2个 |
| 混合策略纳什均衡 | 无（被占优策略排除）| 1个（V/C鹰比例）| 1个（不稳定）|
| 合作/和平是否纳什均衡 | 否 | 否 | 是（其中一个）|
| 演化稳定状态 | 全背叛 | 混合种群 | 取决于初始条件 |
| 社会困境程度 | 高 | 中 | 低 |

## 经典案例

### 案例一：中东地区的"鹰鸽循环"

**背景**：中东冲突中的各方策略选择可以用鹰鸽博弈的演化视角理解。

**博弈建模**：
设"谈判/让步"为鸽策略，"军事行动/施压"为鹰策略。冲突中的资源价值V = 领土/资源/影响力，冲突成本C = 经济损失/人员伤亡/国际制裁。

**演化分析**：
- 当国际调解有效时，C升高→V/C降低→鹰策略比例下降→和平窗口期
- 当一方判断可快速取胜（局部V/C>1）→鹰策略短期占优→冲突升级
- 冲突成本累积→C升高→V/C下降→回到混合均衡

**动态视角**：中东和平进程就是一个V/C比率在时间中振荡的过程——短期内鹰策略可能占优，但长期演化倾向于将种群推向混合均衡。问题在于每次振荡都可能带来不可逆的损失。

### 案例二：网约车平台的价格战

**背景**：滴滴与Uber在中国的竞争可以用鹰鸽博弈分析。

**博弈建模**：
- 鹰策略 = 激进补贴、价格战
- 鸽策略 = 维持价格、保守经营
- V = 市场份额价值（巨大）
- C = 补贴烧钱成本（每月数亿美元）

**动态过程**：
初期：V远大于C（中国市场价值 > 短期亏损）→ V/C > 1 → 双方都选鹰→恶性补贴战
中期：烧钱持续，投资方压力增大→C急剧升高→ V/C 下降
后期：V/C下降到一定程度→混合均衡出现→双方均有动力寻求合作→最终滴滴收购Uber中国

## 核心洞见

> **有限冲突原理**：鹰鸽博弈揭示了自然界和人类社会中一个深刻的法则——当冲突的代价足够高时，即使是"赢家"也是输家。演化不会奖励"永远的鹰"——过于好斗的个体将在鹰对鹰的交锋中消耗殆尽。这就是为什么我们看到的冲突很少是"不死不休"——不是因为没有足够的好斗者，而是因为纯粹的好斗在演化中已经被淘汰了。

> **混合策略的深层含义**：鹰鸽博弈的混合均衡不是指每个个体以概率V/C选择鹰（"混合策略"），而是指在种群中恰好有V/C比例的个体选择纯鹰策略（"多态均衡"）。这两种解释在数学上等价但在生物学上截然不同——后者更符合演化生物学的观察。

## 练习

**练习1（计算）**：在鹰鸽博弈中，假设V=6，C=10。求：(a)混合策略纳什均衡的鹰比例；(b)在此均衡下，鹰和鸽的期望收益各是多少？(c)在均衡处，种群平均收益是多少？

<details>
<summary>查看答案</summary>
(a) p* = V/C = 6/10 = 0.6，即60%鹰，40%鸽。
(b) u(H)=0.6×(6-10)/2 + 0.4×6 = 0.6×(-2) + 2.4 = -1.2+2.4 = 1.2；u(D)=0.6×0 + 0.4×3 = 1.2。均衡收益相等。
(c) 平均收益 = 0.6×1.2 + 0.4×1.2 = 1.2。
</details>

**练习2（分析）**：如果有第三种策略"评估者"（Retaliator）——首先展示，若对方攻击则反击但适可而止——加入鹰鸽博弈会如何改变均衡？请分析三者之间的演化动态。

<details>
<summary>查看答案</summary>
加入评估者(R)后分析其对抗两种策略的收益：
对鸽(D)：评估者展示威胁→鸽退缩→评估者得V/2（保守收益，不会攻击和平的对手）。
对鹰(H)：评估者先展示→鹰攻击→评估者反击但适可而止→双方发生有限冲突。设有限冲突成本为c(<C/2)，则评估者对鹰的收益约为(V-c)/2。
现比较三种策略的入侵抵御能力：
- 鹰种群中：评估者能侵入吗？鹰对评估者≈(V-C)/2，评估者对鹰≈(V-c)/2。如果c<C，评估者在全鹰种群中收益更高→评估者可侵入全鹰种群。
- 鸽种群中：评估者对鸽≈V（展示即得），鸽对评估者=0→评估者收益更高，可侵入。
- 评估者种群中：鹰可侵入吗？鹰对评估者≈(V-C)/2 < (V-c)/2（因为c<C/2），鹰无法侵入。鸽可侵入吗？不能（评估者对鸽占优）。
因此评估者是唯一的演化稳定策略——这就是为什么自然界中"仪式化争斗"（类似评估者）比彻底的鹰或鸽更普遍。
</details>

**练习3（计算）**：考虑一个非对称鹰鸽博弈：大型动物与小动物争夺资源。大型动物的战斗成本CL=4，小动物的战斗成本CS=8，资源价值均为V=4。求非对称混合策略纳什均衡。

<details>
<summary>查看答案</summary>
设大型动物鹰概率为pL，小动物鹰概率为pS。
大型动物均衡条件：uL(H) = uL(D) → pS×(V-CL)/2 + (1-pS)×V = pS×0 + (1-pS)×V/2
即 pS×(0) + (1-pS)×4 = (1-pS)×2 → 4-4pS = 2-2pS → pS = 1。
大中型动物均衡：uS(H) = uS(D) → pL×(V-CS)/2 + (1-pL)×V = (1-pL)×V/2
即 pL×(-2) + (1-pL)×4 = (1-pL)×2 → 4-6pL = 2-2pL → 4pL = 2 → pL = 0.5。
均衡：大型动物50%概率选鹰，小动物总是选鹰。直觉：小动物战斗成本高，但面对大型动物时退缩意味着零收益→于是它们总是战斗，尽管代价不菲。
</details>

**练习4（判断）**："鹰鸽博弈中，如果V<C，那么纯鸽策略是演化稳定的。'判断对错并解释。

<details>
<summary>查看答案</summary>
错误。纯鸽策略不是演化稳定的，因为少数鹰（突变体）可以侵入全鸽种群。在全鸽种群中，鹰的收益=V，而鸽的平均收益=V/2。V>V/2（只要V>0），所以鹰的增长率高于鸽，鹰会迅速扩张。只有当鹰比例达到V/C时，鹰的期望收益才降到与鸽相等，演化达到稳定。
</details>

**练习5（思考）**：在人类社会中，法律和规范可以被理解为一种"提高战斗成本C"的制度设计。请用鹰鸽博弈的框架分析：为什么"法治社会比丛林社会更有利于所有人的福利"？找出V/C比值在其中扮演的角色。

<details>
<summary>查看答案</summary>
法治提高了攻击/欺骗/违约的成本C，降低了V/C比值。
效应一（V/C下降→鹰比例下降）：更低的V/C意味着更少的"鹰"行为，社会从"所有人都是潜在鹰"转变为"大多数人选择合作"。
效应二（均衡收益=u*=V/2增大）：在混合均衡中，u*=(V/2)(1-V/C)。当C→∞时V/C→0，u*→V/2（最大可能的分蛋糕收益）。法治通过提高违规成本，让合作的收益最大化。
效应三（从消耗战到正和博弈）：V-C/2项在鹰对鹰时是负的。降低鹰比例意味着减少这些负和互动，社会资源从"冲突消耗"转向"生产创造"。
定量：若V=100，C=200(丛林)→V/C=0.5→u*=25；C=2000(法治)→V/C=0.05→u*=47.5。社会总福利近乎翻倍。
</details>
