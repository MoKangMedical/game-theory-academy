     1|# 第5课：零和博弈——总收益固定时的策略逻辑
     2|
     3|> 在零和博弈中，我的收益就是你的损失。它把博弈简化为纯粹的冲突——你的目的不是最大化自己的得分，而是在对手也会玩的情况下，最小化最坏的结果。
     4|
     5|## 学习目标
     6|- 精确定义零和博弈并理解其"蛋糕固定"的本质假设
     7|- 掌握极小极大定理的核心思想——在零和博弈中，最小化损失 = 最大化收益
     8|- 学习安全策略和风险态度：为何零和博弈的最佳玩法是"防御而非进攻"
     9|- 能够求解2×2零和博弈（纯策略和混合策略）
    10|- 认识零和博弈在体育、军事、政治竞选、零和谈判中的应用与局限
    11|
    12|## 核心概念
    13|
    14|### 零和博弈的形式定义
    15|
    16|两人零和博弈：玩家1的收益u₁(s₁,s₂)且u₂(s₁,s₂) = -u₁(s₁,s₂)（常数和博弈=零和+固定转移）。意味着双方利益完全对立——没有任何合作空间。
    17|
    18|### 极小极大定理（von Neumann, 1928）
    19|
    20|这是博弈论的第一个伟大定理。对于任何有限的两人零和博弈：
    21|
    22|> max_{σ₁} min_{σ₂} u₁(σ₁,σ₂) = min_{σ₂} max_{σ₁} u₁(σ₁,σ₂) = v
    23|
    24|其中v被称为**博弈的值(Value)**。
    25|
    26|**含义**：
    27|- 玩家1可以保证自己至少得v（无论玩家2做什么）
    28|- 玩家2可以保证玩家1最多得v（无论玩家1做什么）
    29|- 安全的极小极大策略组合(s₁*, s₂*)构成了纳什均衡
    30|- 在零和博弈中，均衡收益是唯一的（虽然均衡策略可能不唯一）
    31|
    32|### 混合策略的重要性
    33|
    34|在绝大多数零和博弈中，纯策略纳什均衡不存在（如硬币匹配博弈）。混合策略成为必需——而极小极大定理正保证了混合策略均衡的存在。
    35|
    36|**混合策略解的逻辑**：
    37|对你来说至关重要的不是猜测对手会出什么——而是让对手无法猜测你会出什么。
    38|

    60|## 经典案例
    61|
    62|### 案例一：警察与强盗（Inspection Game）
    63|
    64|**博弈**：强盗可作案(a)或歇业(n)。警察可巡逻(p)或不巡逻(np)。收益：
    65|- 强盗作案，警察巡逻→抓获，强盗-5、警察+5
    66|- 强盗作案，警察不巡→得手，强盗+3、警察-3
    67|- 强盗歇业，警察巡逻→白费，强盗0、警察-2
    68|- 强盗歇业，警察不巡→皆无，强盗0、警察0
    69|
    70|支付矩阵：
    71|
    72|| B\P | 巡逻 | 不巡 |
    73||-----|-----|------|
    74|| 作案 | -5, +5 | +3, -3 |
    75|| 歇业 | 0, -2 | 0, 0 |
    76|
    77|求混策略：设强盗作案概率p，警察巡逻概率q。
    78|强盗期望：巡逻行-p·5+(1-p)·0 = -5p。不巡行：p·3+(1-p)·0 = 3p。
    79|若警察混合同使得强盗两行动无差异→ -5p = 3p → 无解？等等，警察巡逻时强盗作案是-5,不巡是3。设q=巡逻概率。
    80|强盗期望：E_B = q(-5p) + (1-q)(3p+0·(1-p)) = -5pq + 3p(1-q) = p(-5q+3-3q) = p(3-8q)
    81|当p>0时：若3-8q>0→抢有理 若3-8q<0→不抢有理。均衡需q*=3/8=0.375。
    82|警察期望：E_P = q(p·5+(1-p)(-2)) + (1-q)(p(-3)+(1-p)·0) = q(5p-2+2p) + (1-q)(-3p) = q(7p-2) + (1-q)(-3p)
    83|当q变换：dE_P/dq = 7p-2+3p = 10p-2。均衡→10p*-2=0→p*=0.2。
    84|
    85|均衡：强盗20%作案，警察37.5%巡逻。博弈值=强盗得0（作案率为正但总期望0）。
    86|
    87|### 案例二：网球博弈——发球方向
    88|
    89|**现实中ATP数据**：顶级选手发球方向（宽外角/近身/T点）非常接近均衡频率。如果某选手发外角比例超70%→接球手会预判外角→外角效果下降。这就迫使选手"混合"——达到让接球手无差异预测方向的频率。
    90|
    91|## 核心洞见
    92|
    93|> **在零和博弈中，你的最佳策略是保护自己——而不是试图最大化**：极小极大原则告诉你要"考虑最坏情况并最小化它的伤害"。在零和博弈中这与"最大化自己的收益（在对手最佳反应下）"等价——但在生活中，保险、应急预案、对冲都是极小极大思维的应用。
    94|
    95|> **风险是零和博弈的核心：信息、随机化和"不可预测性"**：你能赢的价值v取决于你的"不可预测性"。如果你的策略被对手猜中→收益<v。这就是为什么在零和博弈中，"可预测的"就是"可被利用的"。

    98|
    99|<details><summary>展开练习</summary>
   100|
   101|**练习1**：2×2零和博弈。求博弈的值和极小极大策略。
   102|
   103|| | L | R |
   104||------|-----|-----|
   105|| U | 3 | 1 |
   106|| D | 2 | 4 |
   107|
   108|<details><summary>查看答案</summary>
   109|设玩家1的U=概率p，D=1-p。设玩家2的L=概率q，R=1-q。
   110|玩家1期望：E1 = p(3q+1(1-q)) + (1-p)(2q+4(1-q)) = p(2q+1) + (1-p)(4-2q) = p(2q+1) + 4-2q -p(4-2q) = p(2q+1-4+2q) + 4-2q = p(4q-3) + 4-2q
   111|∂E1/∂p = 4q-3 = 0 → q* = 3/4
   112|玩家2期望：E2 = q(3p+2(1-p)) + (1-q)(p+4(1-p)) = q(p+2) + (1-q)(4-3p) = q(p+2) + 4-3p -q(4-3p) = q(p+2-4+3p) + 4-3p = q(4p-2) + 4-3p
   113|∂E2/∂q = 4p-2 = 0 → p* = 1/2
   114|均衡：(p*=1/2, q*=3/4)
   115|值v = E1(p*,q*) = (1/2)(4·3/4 -3) + 4 - 2·3/4 = 1/2(3-3) + 4 - 1.5 = 2.5
   116|玩家1期望2.5，玩家2期望-2.5（零和）。
   117|</details>

   119|**练习2**：猜拳博弈。石头(1)剪刀(2)布(3)。设收益为：赢=1，平=0，输=-1。求唯一混合NE。
   120|
   121|<details><summary>查看答案</summary>
   122|对称性→唯一混合NE是等概率(1/3,1/3,1/3)。任何偏离等概率的策略可被对手利用。
   123|若你出石头概率>1/3→对手增加出布的概率(对抗石头)→你的期望下降。
   124|在均衡中每人期望=0。
   125|</details>

   127|**练习3**：扑克简化为两策略博弈：你可"诈唬"或"实牌"。对手可"跟注"或"弃牌"。设诈唬成本=1，被跟注=输2。实牌被跟注赢3，对手弃牌得1。求混合均衡。
   128|
   129|<details><summary>查看答案</summary>
   130|| | 跟注 | 弃牌 |
   131||------|-----|------|
   132|| 诈唬 | -2 | 1 |
   133|| 实牌 | 3 | 1 |
   134|
   135|设你诈唬概率p，对手跟注概率q。
   136|你的期望：E = p(q(-2)+(1-q)1) + (1-p)(q·3+(1-q)1) = p(1-3q) + (1-p)(2q+1) = p-3pq + 2q+1 - 2pq - p = 2q+1 -5pq
   137|∂E/∂p = -5q → 不可能是0除非q=0→但需要q*>0。这不对，检查：E对p系数的分析……
   138|纠正：玩家1纯策略期望：若诈唬→E_bluff = -2q+1(1-q)=1-3q。若实牌→E_truth = 3q+1(1-q)=1+2q。诈唬vs实牌，哪个更好？取决于q。使玩家2混合→让玩家1在二策略间无差异→ 1-3q = 1+2q → q? 不可能→诈唬总是劣势策略(因为-3q<2q对所有q)！
   139|不诈唬是严格劣势？检查：若q=0→诈唬=1,实牌=1→相等。若q>0→诈唬<实牌。存在微小诈唬的可能性？
   140|修正：若诈唬收益改为"跟注输3而非2"，或者加入"虚张声势迫使对手弃牌"的博弈。这是poker博弈深刻之处——极少诈唬但有不为零的概率。
   141|更简化的混合均衡：q*=? 使诈唬无差异需1-3q=1+2q→q=0。在这个收益下不诈唬均衡唯一。若要诈唬存在于均衡需要微调参数。
   142|在实际poker中，由于底池赔率(对手必须跟注>1/4时间)，诈唬和实牌频率被精算。
   143|</details>

   148|1. 工资谈判：工人想高薪，雇主想低成本→看似零和。但高薪可提升士气/吸引力/流失率降低→长期双方受益→非零和。

   155|
   156|<details><summary>查看答案</summary>
   157|象棋/围棋是零和博弈（赢=1,输=-1,平=0）。AI在训练中追求逼近极小极大(即最大min期望)。AlphaGo通过MCTS逼近极小极大值v。

   159|所以AI下棋是零和博弈的极小极大求解器的完美实例。

### 🎯 深度学习：打通理论与直觉

> 学博弈论不是为了记住一百个定义——是为了形成**博弈直觉**。当你看到一个多人竞争的场景，自动识别出博弈类型、均衡候选和偏离激励——你就真正消化了这门学问。

---

#### 进阶练习
**练习A — 案例迁移**：选择一个你生活中的真实场景（朋友聚会费、项目分工、价格谈判），用本课的博弈论框架重新分析。写下：
1. 玩家及各自的策略空间
2. 回报函数（你的假设）
3. 预测的纳什均衡
4. 实际发生的结果
5. 若两者不同，为什么？

<details><summary>参考框架</summary>
- 第一步：画博弈表格或树，明确所有可行的选择组合。
- 第二步：标出每个结果的回报值——即便只是推断。
- 第三步：逐格检查——有没有人有动机单方面换策略？没有的那格就是纳什均衡。
- 第四步：对比现实——若现实与均衡不同，可能是信息不对称、非理性行为、或你定义的回报函数有误。
</details>

**练习B — 反事实分析**：假定博弈的一个关键条件改变了（例如：从一次性博弈变成了重复博弈，或信息从不对称变为完全对称），均衡会如何变化？这对现实决策有什么启示？

<details><summary>提示</summary>
- 重复博弈→引入声誉和惩罚→合作均衡可能出现（TFT生效）。
- 信息从不完全变完全→信号不再需要→均衡可能更简单也更残酷（买家知道你的成本底线）。
- 这种"如果…就…"的思维练习，正是博弈论的实战价值所在。
</details>

**练习C — 机制设计挑战**：如果你可以在这个博弈中引入一条新规则（如：信息披露要求、顺序改变、惩罚机制），你会设计什么样的规则来改善结果？这条规则需要满足什么条件才能自执行？

<details><summary>思路参考</summary>
一个"好"的机制要满足：(a) 激励相容——人们自愿遵守；(b) 个体理性——参与比不参与好；(c) 预算平衡（若是经济机制）——不需要外部资源补贴。例如：从"谁洗碗"改成"轮流洗碗+不洗的一方负责明天做饭"——既激励相容，又不需要外部裁判。
</details>
